# Excel Portfolio

Hi, I'm Mohamed — this repo collects the Excel projects I'm building while learning data cleaning, PivotTables, and dashboard design. Each project folder has the workbook and a written breakdown of what I found.

## Projects

### Bike Sales Dashboard
Cleaned a 1,000-row customer dataset and engineered an age-bracket field with a nested IFS formula, then built three PivotTables — income by gender, purchase rate by commute distance, purchase rate by age — and combined them into an interactive Dashboard with slicers.

## Tools & Skills 

  
- Excel: PivotTables, PivotCharts, IFS formulas, slicers
- Data cleaning: feature engineering, categorical bucketing
